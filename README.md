# Smart Scheduler Chooser

Minor project (PDEU): AI-Agent-Based Cloud–HPC Workload Orchestration.

A simulator of a computing cluster that can rent cloud machines, used to compare scheduling rule sets (and, later, rule / ML / LLM "choosers" that switch between them) on late jobs, waiting time and cloud cost.
